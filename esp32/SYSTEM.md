# نظام حد السرعة على ESP32-S3: كل البيانات

آخر تحديث: 2026-10-04. نفس فكرة تطبيق الجوال (حد السرعة للشارع اللي أنت فيه، وتنبيه لما تتجاوزه)، لكن على قطعة مستقلة تشتغل بدون إنترنت.

## القطع

| القطعة | التفاصيل |
|---|---|
| البورد | ESP32-S3 (QFN56، revision v0.2)، فلاش 16 ميجا، PSRAM مدمجة 8 ميجا، شريحة USB: CH343 (تظهر COM7) |
| الـGPS | u-blox **MAX-M10S** (تتكلم NMEA، سرعتها **38400**) |
| الشاشة | IPS دائرية 1.28 بوصة، 240×240، المتحكم GC9A01 |
| كرت SD | غير مركّب. الخريطة داخل فلاش الشريحة (`USE_SD 0`) |
| البزر | غير مركّب (`BUZZER_PIN -1`)، التنبيه بالشاشة فقط |

## الأسلاك (من ملف `speed_limit/config.h`)

| الوصلة | GPIO |
|---|---|
| الشاشة SCK / MOSI / CS / DC / RST / BL | 12 / 11 / 10 / 9 / 8 / 7 |
| الـGPS: سلك TX حقها ← ESP32 | 18 (تأكدت منه بفحص فعلي) |
| الـGPS: سلك RX حقها ← ESP32 | 17 (غير مفحوص، ما نحتاجه للقراءة) |
| زر التجربة (BOOT) | 0 |
| أطراف كرت SD (احتياط، لو رجعنا له) | SCK 13، MISO 14، MOSI 15، CS 16 |

## ذاكرة الفلاش (16 ميجا)

ملف `speed_limit/partitions.csv`:

| القسم | البداية | الحجم | المحتوى |
|---|---|---|---|
| nvs | 0x9000 | 0x5000 | إعدادات النظام |
| phy_init | 0xE000 | 0x1000 | |
| factory | 0x10000 | 2 ميجا | البرنامج |
| **map** | **0x210000** | **6 ميجا** | **الخريطة `roads.bin` (نظام ملفات LittleFS)**. الخريطة الحالية 3.8 ميجا، تغطي المدينة المنورة |

## كيف يشتغل

1. يقرأ الموقع والسرعة والاتجاه من الـGPS (مكتبة TinyGPSPlus).
2. يدوّر في `roads.bin` على أقرب شارع في مربع الخريطة الحالي، ويفضّل الشارع اللي اتجاهه يوافق اتجاه سيرك (نفس منطق `index.html` في التطبيق).
3. إذا الشارع له حد مسجّل يعرضه. وإذا لا، يعرض حداً **تقديرياً** حسب نوع الشارع (إطار متقطع وكلمة EST).
4. إذا سرعتك أعلى من الحد بأكثر من **2 كم/س**، تفلّش الدائرة بين الأبيض والأحمر.
5. لو ما فيه GPS: تظهر «NO GPS» مع عدد الأقمار (المستخدمة/الظاهرة) وأعمدة إشارة. وإذا الوحدة ما ترسل شيئاً: «NO DATA / CHECK WIRES».

## تعديل شكل الشاشة

1. افتح **Screen Editor** (أو `esp32/theme-editor.html`) وعدّل بالمعاينة.
2. اضغط «حفظ theme.h»، وانسخ الملف فوق `esp32/speed_limit/theme.h`.
3. ارفع البرنامج (الأمر تحت).

## الأوامر (PowerShell)

الأدوات: Arduino CLI 1.5.1، حزمة esp32 رقم 3.3.12، مكتبة GFX Library for Arduino 1.6.8، مكتبة TinyGPSPlus 1.0.3.

ترجمة البرنامج ورفعه:

```
arduino-cli compile --fqbn esp32:esp32:esp32s3:FlashSize=16M esp32\speed_limit
arduino-cli upload -p COM7 --fqbn esp32:esp32:esp32s3:FlashSize=16M esp32\speed_limit
```

تحديث الخريطة (إذا غيّرتها أو لمنطقة ثانية). أولاً `scripts\build-roads.ps1` يطلع `roads.bin`، بعدين تبني صورة القسم وتكتبها في الفلاش:

```
mklittlefs -c data -p 256 -b 4096 -s 6291456 map.bin
esptool --chip esp32s3 -p COM7 -b 921600 write-flash 0x210000 map.bin
```

(مجلد `data` فيه ملف `roads.bin` فقط. الأداتان موجودتان تحت `%LOCALAPPDATA%\Arduino15\packages\esp32\tools\`.)

فحص الـGPS: ارفع `esp32/gps_test` وافتح السيريال على 115200.
